# استخراج دیدگاه‌های کافه‌بازار

اکستنشن Chrome برای بارگذاری دیدگاه‌های صفحهٔ اپ در کافه‌بازار و ذخیرهٔ آن‌ها در فایل CSV با ستون‌های شناسه، نام کاربری، امتیاز، تاریخ، متن، پسندها و تعداد رأی‌ها.

## نصب در Chrome

1. در Chrome به `chrome://extensions` بروید.
2. گزینهٔ **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و همین پوشه را انتخاب کنید.
4. صفحهٔ اپ موردنظر را در `cafebazaar.ir` باز کنید و روی آیکن اکستنشن بزنید.
5. نام فایل را بررسی کنید و **شروع استخراج** را بزنید. پس از دانلود، CSV را از پوشهٔ دانلودهای Chrome باز کنید.

اگر ساختار HTML یا کلاس‌های صفحهٔ کافه‌بازار تغییر کرده باشد، ممکن است لازم باشد انتخابگرهای `content.js` به‌روز شوند.
